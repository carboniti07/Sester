sesterAgent APIs that charge,
limit and prove.

One ASGI middleware plugs x402-style metering, per-agent quotas, fail-closed spend policy and a tamper-evident receipt ledger into your API — with zero required dependencies. Four agent-commerce protocols compile onto one wire-format core.

GitHub PyPI Discussions

⚖️ Meter

Every paid request passes a 402 → payment → receipt handshake. Spend is metered in integer minor units — no float drift, ever.

🚧 Limit

Per-agent daily quotas, burst caps, time-window policy and human-approval escalation — decided before your handler runs.

🔗 Prove

Every charge and denial lands in a hash-chained ledger. Auditors verify bundles with nothing but sha256.

60-second demo

docker run --rm -p 8402:8402 ghcr.io/goun7/sester-demo:latest
# open http://127.0.0.1:8402/panel

# or
pip install "sester[demo]"
uvicorn sester.demo_api:app --port 8402
Unpaid call → 402 challenge. Paid call → 200 + receipt header. 5th call → 402 quota exceeded. The panel shows who paid what — with a live chain-integrity badge.
